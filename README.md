## 📍 ESP32 UWB Real-Time Positioning System

**ESP32 · DW1000 · C++ · Python · Serial Communication**

Developed a real-time indoor positioning and ranging system using **ESP32 and DW1000 Ultra-Wideband modules**.

### Key Features

- Multi-anchor UWB distance measurement
- Real-time position tracking
- ESP32 ↔ Python serial communication
- JSON-based data transmission
- Real-time trajectory visualization
- Noise filtering and outlier rejection
- Position recording and trajectory analysis

The system combines embedded hardware, wireless ranging, data processing, and Python visualization to create a complete real-time tracking solution.
